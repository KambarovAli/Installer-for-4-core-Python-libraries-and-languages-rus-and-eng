\# 📦 Python Base Installer for Lazy Developers / Установщик базовых библиотек для ленивых(не обижайтесь лол)



\[EN] A simple, double-click solution to install a core set of Python libraries without writing any code manually. Perfect for setting up a fresh environment or sharing with friends.



\[RU] Простое решение в один клик для установки базового набора библиотек Python без необходимости писать код вручную. Идеально подходит для быстрой настройки окружения или отправки друзьям.



\---



\## 🛠️ What's Inside / Что внутри



\* \*\*pygame\*\* — For creating simple games and windowed interfaces / Для создания простых игр и оконных интерфейсов.

\* \*\*numpy\*\* — Basic library for working with arrays / Базовая библиотека для работы с массивами.

\* \*\*beautifulsoup4\*\* — HTML and XML parsing (lightweight) / Парсинг HTML и XML (весит мало).

\* \*\*requests\*\* — Library for working with HTTP requests / Библиотека для работы с HTTP-запросами.



\---



\## 🚀 How to Run / Как запустить



\### 🇷🇺 Инструкция на русском языке:

1\. \*\*ВАЖНО:\*\* Обязательно полностью \*\*разархивируйте ZIP-архив\*\* перед запуском! Если запустить прямо из архива, скрипт выдаст ошибку (хотя батник об этом предупредит).

2\. Дважды кликните по файлу `run.bat`.

3\. Если у вас на компьютере вообще нет Python, официальный лаунчер Windows сам предложит его скачать. Просто введите латинскую букву `y` в консоли и нажмите \*\*Enter\*\*.

4\. Скрипт сам установит все 4 библиотеки.



\### 🇺🇸 English Instruction:

1\. \*\*IMPORTANT:\*\* Make sure to completely \*\*extract the ZIP archive\*\* before running! Running it directly inside the archive will cause an error (though the batch file will warn you).

2\. Double-click the `run.bat` file.

3\. If Python is missing on your machine, the official Windows Python Launcher will automatically prompt you to download it. Just type `y` in the console and press \*\*Enter\*\*.

4\. The script will automatically install all 4 libraries.

\* Windows 10 / 11
